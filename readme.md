- 编译器会把没用到的函数、变量也编译进去，会占用空间

- 实际测试，芯片的定时器可能有1%的误差，例如，设置1ms的定时中断，每隔1s会有几ms的误差

- 使用PLL x6倍频作为系统时钟，串口波特率设置为115200，每隔100ms给芯片发送4字节的数据，芯片可以接收，每隔10ms给芯片发送数据，芯片有概率丢失数据
  - 波特率改成38400也是这样
  - 发送端要注意，每隔100ms再给芯片发送一次数据

- 使用串口发送数据时，受制于芯片硬件性能，要每隔一段时间才能发送一次数据，测试每隔10ms发送4个字节的数据，可以正常工作。
  - 如果在主循环一直发送数据，会导致程序卡死

- 如果点亮了多个灯，只给板子5V供电，会因为电流不够，导致灯珠无法点亮，用12V供电可以正常点亮
