- 编译器会把没用到的函数、变量也编译进去，会占用空间

- 实际测试，芯片的定时器可能有1%的误差，例如，设置1ms的定时中断，每隔1s会有几ms的误差

- 使用PLL x6倍频作为系统时钟，串口波特率设置为115200，如果每隔 50ms以下给串口发送 30 字节的数据，会有概率阻塞，导致芯片卡死和复位。
  - 现在每隔50ms，给芯片发送30个字节的数据，芯片可以正常打印出来，不会有丢包

- 如果点亮了多个灯，只给板子5V供电，会因为电流不够，导致灯珠无法点亮，用12V供电可以正常点亮
